## Rule
`GCP_INTEROP_KEY` is stored as a Replit secret. `GcpUpdateService` reads it via `Environment.GetEnvironmentVariable("GCP_INTEROP_KEY")` and sends as `X-GCP-Interop-Key` header.

**Agreed endpoint structure (pending Resolver restructuring):**
```
/tools/gcp/interop/                     ← auth boundary; ALL sub-paths keyed
/tools/gcp/interop/current/
    GCPPrefixFormatList_YYYY-MM-DD.xml  ← original GS1 filename preserved
    diff-report.[format]                ← generated by Resolver on each update
/tools/gcp/interop/previous/
    GCPPrefixFormatList_YYYY-MM-DD.xml
```

**VTCCP receives:** original GS1 XML full text (not data.json). GcpLengthTable already parses it. GcpUpdateService currently points to flat `current.xml` alias — update URL to new path when Resolver restructuring is complete.

**Decoder separation:** Decoder moved off /interop/ path to avoid auth conflict. Future home: My2DirRetail.com (Azure Static Web Apps, free tier) with Azure Function proxy adding the key. Interim: separate path on Resolver site.

**Why:** Browser JS cannot hold a secret key; flat /interop/ path conflicts with auth-gating the decoder page. One auth boundary covering all of /interop/* is cleaner.

**data.json:** Do NOT use in VTCCP — not intended to be public; off-limits per explicit user decision.
