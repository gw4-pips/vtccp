PCM.METRIC-PARM-THRESHOLD

Set the raw value threshold for the selected quality standard, metric and grade (e.g. AIM-DPM → UEC → Threshold B = 50). Not all metrics are available for each standard: AIM-DPM (0, 1, 3, 4, 6, 8), ISO-IEC 15415 (0, 1, 3, 4, 6), ANSI-ISO-IEC 15416 (1, 4, 8, 9, 23, 25), 1D readability (0, 2, 8, 9, 11), DotCode (0, 1, 2, 3, 6, 8)
