   - DM: 7 × 2 = `14` ✓

### Confirmed structural limits (permanent for firmware 6.1.16_sr4)
- **ULQZ/URQZ/RUQZ/RLQZ grades**: NOT in push channel. Objects exist but return
  `{grade:"X", numericGrade:8.8}` (firmware-internal compound grade, not ISO letter).

  Same `{raw:-1, grade:X, numericGrade:8.8}` pattern.
- **DataCodewords / ECBudget**: NOT in push channel. Not in q.general.
- **ErrorCorrectionLevel for QR**: NOT in push channel. Not in q.general.
  Needs A1 (DMCC guide) for alternative path.

  includes ECC codewords (full total) or data codewords only; ea array entry count.

  whether `"("` is the complete grade value or a truncation artifact.
