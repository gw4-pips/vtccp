## Architecture decision: DataCodewords / ECBudget

`q.symbols[0]` confirmed null on fw 6.1.16_sr4 — no firmware path to these values
in the push channel. DMST displays them correctly from its own internal tables.

**Resolution**: C# push parser fills DataCodewords and ErrorCorrectionBudget from
ECC200DataCodewordsTable (already in CodewordValuesData.cs) when push delivers ''.
MatrixSize ("16x36") is always present and is the lookup key.
ECC200 table confirms: 16×36 → DataCW=32, ECBudget=24 ✓ (matches DMST exactly).
