## CRITICAL FINDING — DecodeGrade='F' on a successfully decoded symbol

`DecodeGrade = 'F'` (push) / DECODE=0.0(F)/FAIL (DMST)  
`DecodedData = 12345ABCDE...` — symbol decoded successfully

Explanation from DMST footer note: *"Decode grade F, grade is reported using proprietary Decode."*

- **Cognex proprietary Decode** measures how difficult the symbol is to decode
  (margin to decoding failure), NOT whether the symbol actually decoded
- **ISO 15415:2011 standard grade** does NOT include the proprietary DECODE parameter
- `OverallGrade = 'D'` (from MOD=D, RM=D minimum) — the ISO standard grade, correct
- `ApplicationPass = 'Fail (Quality)'` — captures the DECODE=F as a Custom/proprietary fail
- `ApplicationPassReason = 'Quality'`

**VTCCP design (confirmed):** Use `OverallGrade` (ISO standard) as primary grade.
`ApplicationPass` = "Fail (Quality)" is supplemental — documents DECODE=F.
Never let `ApplicationPass` override `OverallGrade`.

- Total: **28 codewords**

`EncodedCharacters = 28` in push = this count.  
`q.general.encodedCharacters` (the fix for bug #1) should give **50** (the actual char count).
