In the aerospace industry, Text Element Identifiers (TEIs) are standard data qualifiers defined in the Air Transport Association (ATA) Common Support Data Dictionary (CSDD). They are primarily used to format machine-readable data strings (like 2D Data Matrix barcodes) for Item Unique Identification (IUID) and global part traceability.The following table details the standard TEIs used to encode aerospace components for life-cycle traceability:TEI CodeData ElementDescriptionFormat / ExamplesMFRManufacturer / Enterprise IDThe identifier of the manufacturer (e.g., CAGE code, DUNS, or ISO code)MFR 12345PNOPart NumberThe current product or part identifier assigned by the design/responsible organizationPNO 98765-101SERSerial NumberThe unique serial number for the specific unitSER 0023SEQSequence NumberA unique sequential tracking number assigned to the partSEQ 0001UCNUnique Component ID NumberUsed if an organization other than the original manufacturer accomplishes serializationUCN ABC1234LOTLot NumberThe lot or batch number to which the specific item belongsLOT 50921-AECIExport Control Flag/IndicatorDesignates if the item is subject to export control and/or restrictions (e.g., Wassenaar Arrangement)ECI [Value]NSTNational Stock Number (NSN)The official 13-digit federal item identification numberNST [Value]OEIOriginal Enterprise IdentifierThe enterprise identifier of the original manufacturer (if different from current)OEI [Value]OPNOriginal Part NumberThe part number assigned by the original equipment manufacturer (OEM)OPN [Value]BPNBase Part NumberThe base part number without any dash numbers or revision detailsBPN [Value]REVRevision NumberThe current configuration revision level of the partREV BHow TEIs are ImplementedIn aerospace, these tags are encoded following the ISO/IEC 15434 syntax.
