## 2. DIAGNOSTIC PROCESS

### Step 1 — Snapshot of broken state
DM-Snapshot-Now.ps1 was run immediately on session start (reader broken, DMST
closed). Two anomalous parameters were identified vs factory default:

```
IMAGE.SIZE  = 1   (factory default = 1 — later confirmed NOT anomalous)
LIVEIMG.MODE = 2  (set dynamically by DMST on connect — confirmed normal)
```

### Step 2 — IMAGE.SIZE investigation
IMAGE.SIZE was initially suspected as the cause and corrected to 0. This was
subsequently confirmed to be WRONG — IMAGE.SIZE=1 (Quarter) IS the factory
default and the correct operating value. Setting it to 0 was an error.

### Step 3 — CONFIG.DEFAULT + full restore
CONFIG.DEFAULT + CONFIG.SAVE + REBOOT was performed. Settings were restored
one at a time via DMST UI with TC panel verification after each addition:

  - CAMERA.MIRROR-HORIZONTAL = ON       ✓ no effect on TC panel
  - CAMERA.MIRROR-VERTICAL = ON         ✓ no effect on TC panel
  - NTP.ENABLE + servers + timezone     ✓ no effect on TC panel
  - TRUCHECK.COMPANY-NAME (full name)   ✓ no effect on TC panel
  - TRUCHECK.OPERATOR-NAME = GW4        ✓ no effect on TC panel
  - TRUCHECK.CUSTOM-NOTE                ✓ no effect on TC panel
  - TRUCHECK.APPLICATION-STANDARD = 4  ✓ no effect on TC panel
  - TRUCHECK.APERTURE = 0               ✓ no effect on TC panel
  - TRUCHECK.APERTURE-SIZE = 80         ✓ no effect on TC panel
  - DECODER.ROI = 368 1968 604 1308     ✓ no effect on TC panel
  - SYMBOL.QR = ON                      ✓ no effect on TC panel
  - All other symbologies               ✓ no effect on TC panel
  - Push script v1.36 loaded            ✓ no effect on TC panel

TC panel image remained present throughout all additions.

### Step 4 — VTCCP connect test (no scan)
VTCCP connected. Snapshot run immediately after connect.
Result: ZERO parameter changes. SDK Connect() writes nothing to the reader.

### Step 5 — VTCCP trigger test
VTCCP triggered a scan. Snapshot run immediately after.
Result: ZERO parameter changes. IMAGE.SIZE remained 1. IMAGE.FORMAT remained 1.
The current VTCCP build does NOT corrupt any reader parameter during
connect, trigger, or disconnect.

### Step 6 — Software reboot test
REBOOT command issued via DMCC. Reader restored from NVRAM.
Snapshot confirmed all parameters intact after reboot.
TC panel image confirmed working after reboot with DMST open.
